# VotacionesYElecciones

El proyecto conserva el nombre y el paquete Kotlin del ZIP original y usa el diseño y las herramientas de la versión actual del repositorio.

| Configuración | Valor |
|---|---|
| Proyecto y nombre visible | VotacionesYElecciones |
| Namespace y paquetes Kotlin | com.daniel.votacionesyelecciones |
| Identificador de instalación | com.daniel.votacioneselecciones |
| Firebase | registrovotaciones-1799e |
| Versión | 1.6 (9) |

El identificador de instalación se conserva para usar la configuración Firebase existente y mantener la identidad de la aplicación. No es necesario crear otra app en Firebase por cambiar el namespace.

Se incluyen el diseño del asistente y del dictado, los modelos preparados al compilar, el calendario electoral y el diagnóstico de errores Firebase. Consulta el README para abrir, compilar y probar el proyecto.

La carpeta no incluye cachés, configuración local de Android Studio ni paquetes de instalación antiguos. Gradle descarga los modelos en la primera compilación. Las reglas de Firestore se publican por separado desde Firebase Console.
