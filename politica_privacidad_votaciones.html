2. Datos que trata la aplicación

La aplicación integra herramientas de Google Firebase para autenticación, almacenamiento, analítica, notificaciones y diagnóstico de fallos. Según las funciones que utilice cada persona, se pueden tratar las siguientes categorías:

  • Cuenta e identificación: dirección de correo electrónico, identificador de usuario y datos necesarios para iniciar sesión mediante Firebase Authentication. Las contraseñas son procesadas por el servicio de autenticación y no deben almacenarse en texto plano por la aplicación.
  • Elecciones y votaciones: información ingresada para crear elecciones, candidatos, votos y resultados a través de la aplicación y de Firebase Firestore. Los votos se vinculan mediante cuentas.
  • Datos de uso: eventos y datos técnicos que pueden recopilarse con Firebase Analytics para comprender el funcionamiento de la aplicación.
  • Diagnóstico: reportes de errores, datos de funcionamiento, información técnica del dispositivo y registros relacionados con fallos que puede procesar Firebase Crashlytics.
  • Notificaciones: identificadores de registro del dispositivo o tokens usados por Firebase Cloud Messaging, si se habilitan notificaciones.

3. Finalidades del tratamiento

Los datos se utilizan para permitir el acceso a las cuentas, administrar elecciones y candidatos, registrar y mostrar votaciones y resultados, enviar notificaciones cuando proceda, mejorar la estabilidad de la aplicación y analizar su funcionamiento técnico.

4. Servicios externos y comunicación de datos

La aplicación utiliza servicios de Google Firebase, incluidos Firebase Authentication, Cloud Firestore, Google Analytics for Firebase, Firebase Crashlytics y Firebase Cloud Messaging. Estos proveedores pueden tratar información necesaria para prestar sus servicios conforme a sus propias condiciones y documentación de privacidad.

Consulta la información de privacidad de Firebase y la política de privacidad de Google.

5. Conservación y seguridad

Los datos de la aplicación se conservan durante Todo el uso de la app. Los datos almacenados en Firebase se encuentran sujetos a las medidas de seguridad del servicio y a las reglas de acceso configuradas por el responsable. Ningún sistema garantiza seguridad absoluta.

6. Derechos, solicitudes y eliminación de cuentas

Los usuarios pueden solicitar información, corrección o eliminación de datos personales escribiendo a d.lobos.0706@gmail.com. En la solicitud deben indicar cómo identificar la cuenta, sin enviar contraseñas.

7. Privacidad de las votaciones

Los registros de voto y los resultados se gestionan para el funcionamiento de las elecciones dentro de la aplicación.

8. Cambios en esta política

La política puede actualizarse cuando cambien las funciones, servicios o prácticas de tratamiento de datos. La fecha de actualización se indicará al comienzo de este documento.
